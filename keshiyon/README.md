# KESHIYON — 消し四目並べ ルールブック

GitHub Pages向けの静的なルール案内サイトです。ビルド、Node.js、サーバーは不要です。

## 既存の KESHIYON-WEB に追加する場合（おすすめ）

今のゲーム画面を上書きしないよう、リポジトリ内に `rules` フォルダを作ります。

1. リポジトリのルートに `rules` フォルダを作成します。
2. このフォルダ内の `index.html`、`styles.css`、`script.js` を `rules/` の中へアップロードします。
3. 既存の `index.html` はそのまま残します。
4. 公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/rules/` になります。

ゲームのホームページからリンクを追加する場合は、`rules/` へのリンクを設置してください。

## ルールサイトだけを別リポジトリで公開する場合

1. `index.html`、`styles.css`、`script.js` をリポジトリのルートにアップロードします。
2. GitHubの **Settings → Pages** で公開元ブランチとルートフォルダを選択します。

## ルールについて

ルール内容は、KESHIYONの提供されたPython版ゲームロジックに合わせています。特に、得点判定、得点時のロック／削除処理、帽子マスの扱い、空きマスが残り1～2マスで同点のときの盤面拡張、盤面が埋まったときの追加点・終了判定を説明しています。

このサイトはルールを読むための静的ページで、ゲーム対局やデータ保存機能は含みません。
