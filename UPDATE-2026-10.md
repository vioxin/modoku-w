# modoku-w: Loading / Sidebar / Mobile update

## What changed

- Added `modoku-common.js` and `modoku-common.css` and linked them from all 27 HTML pages.
- Added a full-screen `NOW LOADING` overlay for requests sent to Google Apps Script web-app URLs. It is delayed briefly so fast requests do not cause distracting flashes, and concurrent requests are counted.
- Fixed the top-page sidebar being clipped by header styles (`backdrop-filter` / `overflow: hidden`) by moving the sidebar element under `body` at DOM ready and keeping it viewport-fixed with independent scrolling.
- Added responsive viewport metadata where it was missing and common small-screen styles for forms, content cards, tables, buttons, legacy layouts and DM/slot/game pages.

## Deploy

Upload the contents of this ZIP to the same website hosting location and allow the new files `modoku-common.css` and `modoku-common.js` to be uploaded. This change is on the website front end; no Apps Script or spreadsheet redeployment is required.

## Notes

- The loading overlay is shown for detected Apps Script web-app requests, not every ordinary network request.
- Existing Apps Script endpoint URLs and spreadsheet data logic were not changed.
- The mobile styles are shared across all HTML pages; game pages retain their existing game logic and controls.
