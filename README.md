# modoku-w — Halloween Edition 2026 + modoku SNS

既存の掲示板・ゲーム・ツールを残しながら、ハロウィンテーマを適用したバージョンです。SNS機能を追加しています。

## リニューアル内容
- `halloween.css` を追加し、夜色・パンプキンオレンジ・ラベンダーでサイト共通の雰囲気を統一。
- Adobe Fonts / Typekit の `https://use.typekit.net/etu8ort.css` を読み込み、フォントフェイスを検出して適用。読み込み失敗時は日本語フォントへフォールバック。
- `sns.html` を追加し、X風のSNS UIを実装。
- 既存ホーム・スレッド・お知らせ・画像掲示板・マイページからSNSへ移動できるリンクを追加。

## SNS機能
タイムライン、投稿・返信・編集・削除、いいね、リポスト、引用、ブックマーク、画像／動画URL添付、投票、ハッシュタグ・メンション、検索、トレンド、プロフィール、フォロー、通知、DM、リスト、コミュニティ、下書き、予約投稿、ミュート、ブロック、通報を含みます。Grokは含みません。

### ローカルデモ
`sns.html` を開くとデモユーザー／サンプル投稿で操作を試せます。API URLが未設定の場合、投稿データはそのブラウザーの `localStorage` にのみ保存されます。別端末・別ユーザーと共有されません。

### 複数人で共有する
`sns-backend/SETUP.md` を参照し、Google Sheets + Apps Script バックエンドをデプロイしてください。利用者ごとに `Users` シートへSNSアクセスキーを登録し、各自がSNS設定画面にウェブアプリURLと自分のキーを保存します。

## 現時点の制限
これはXと完全に同等のサービスではありません。リアルタイム音声スペース、ライブ配信、画像・動画ファイルそのもののアップロード、プッシュ通知、広告・収益化、高度なレコメンドや通報審査画面は含まれません。Apps Scriptは小規模向けです。公開前に `sns-backend/SETUP.md` の認証・プライバシー・運用上の注意を確認してください。

## modoku SNS（全員共通モード）

- SNSページ：`sns.html`
- 全員共通APIの設定ファイル：`sns-config.js`
- Google Apps Scriptバックエンドと初回設定：`sns-backend/SETUP.md`
- 管理者がAPI URLを `sns-config.js` に一度登録してサイトを再公開すると、利用者は通常のmodoku-wログインだけでSNSを利用できます。
- `sns-config.js` が空の場合はローカルデモです。ローカルデモの投稿は他の利用者と共有されません。
